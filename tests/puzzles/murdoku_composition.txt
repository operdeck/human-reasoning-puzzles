# Neutral 4x4 example composing the Murdoku format features.

Size: 4
Regions:
a: Atrium
b: Gallery
c: Studio
d: Courtyard
Grid:
a a b b
a c b b
c c d d
c d d d
AreaTags:
north: Atrium Gallery
west: Atrium Studio
daylight: Gallery Courtyard
Hatched:
west
Objects:
tree: blocking r1c4 r2c4
bench: standable r4c2
EdgeItems:
archway: door r2c2 r2c3
window: window r3c4
PointObjects:
fountain: r3.5c1.5
Marks:
quiet: r1c1 r2c1 ; alone
People:
Ada
Bo
Cal
Dee
Attributes:
trained: Cal Dee
Roles:
navigator: 1 different_regions
recorder: 3 different_regions
RoleEligibility:
navigator: attribute:trained
Clues:
Bo on edge_item:archway
Cal on edge_item:window
Dee on point_object:fountain
Dee on object:bench
Ada on mark:quiet
Bo dir:up attribute:trained
Cal is role:navigator
Ada is role:recorder
Bo is role:recorder
Cal is role:recorder
every role:navigator is role:recorder
if Cal is role:navigator then Cal in tag:daylight
count people on object:bench = 1
count people in tag:north = 2
count role:navigator = 1
count role:recorder = 3
count attribute:trained = 2
count empty areas = 1
count empty areas in tag:west = 1
count empty free cells in mark:quiet = 1
count empty free cells in rows:1-4 = 10
