# Neutral 4x4 example composing the Murdoku format features.

Size: 4
Regions:
a: Atrium
b: Gallery
c: Studio
d: Courtyard
Grid:
a a b b
a c b b
c c d d
c d d d
AreaTags:
north: Atrium Gallery
west: Atrium Studio
daylight: Gallery Courtyard
Hatched:
west
Objects:
tree: blocking r1c4 r2c4
bench: standable r4c2
EdgeItems:
archway: door r2c2 r2c3
window: window r3c4
PointObjects:
fountain: r3.5c1.5
Marks:
quiet: r1c1 r2c1 ; alone
People:
Ada
Bo
Cal
Dee
Attributes:
trained: Cal Dee
Roles:
navigator: 1 different_regions
recorder: 3 different_regions
RoleEligibility:
navigator: attribute:trained
Clues:
on Bo edge_item:archway
on Cal edge_item:window
on Dee point_object:fountain
on Dee object:bench
on Ada mark:quiet
dir Bo attribute:trained up
has Cal role:navigator
has Ada role:recorder
has Bo role:recorder
has Cal role:recorder
subset role:navigator role:recorder
if has Cal role:navigator then in Cal tag:daylight
count people on object:bench = 1
count people in tag:north = 2
count people with role:navigator = 1
count people with role:recorder = 3
count people with attribute:trained = 2
count empty areas = 1
count empty areas in tag:west = 1
count empty cells in mark:quiet = 1
count empty cells in rows:1-4 = 10
